API dos scripts de mod (referência)

Gerada do próprio jogo (src/Automacao.Session/Scripting/ScriptApiDocs.cs): não edite à mão. Como começar: Como fazer um mod, seção Scripts. Campos do JSON: Campos do JSON. Para o VS Code mostrar tudo isto enquanto você escreve, copie mekzorio.d.ts para a pasta scripts/ do seu mod.

Esta é a API de mods 1 ("apiVersion": 1 no manifest.json; sem o campo, vale 1).

import { events, world, players, storage, commands, buildings, enemies, ui, research, contracts, after, random, console } from "mekzorio";

events

Eventos do jogo: o script registra funções que o jogo chama.

Membro O que faz
events.onTick(ticks: number, fn: (tick: number) => void): void Chama fn a cada ticks ticks (30 ticks = 1 segundo). onTick(fn) = todo tick.
events.on(name: string, fn: (data: any) => void): void Forma geral dos eventos abaixo, pelo nome ("playerJoin", "craft"…).
events.onPlayerJoin(fn: (player: Player) => void): void Um jogador entrou.
events.onPlayerLeave(fn: (p: { id: number; name: string }) => void): void Um jogador saiu.
events.onChat(fn: (m: { player: Player; text: string }) => void): void Mensagem no chat (comandos /… não chegam aqui).
events.onBuild(fn: (b: BuildingInfo) => void): void Uma construção foi posta (por jogador ou script).
events.onRemove(fn: (r: { id: number; x: number; y: number }) => void): void Uma construção saiu do mundo.
events.onCraft(fn: (c: { building: BuildingInfo; recipe: string }) => void): void Uma máquina terminou uma receita. Só é registrado se algum script ouve (não pesa à toa).
events.onResearch(fn: (r: { tech: string }) => void): void Uma pesquisa terminou (infinita: a cada nível).
events.onContract(fn: (c: { contract: string; region: number }) => void): void Um contrato de Nó foi cumprido.
events.onDeath(fn: (d: { player: Player }) => void): void Um jogador caiu.
events.onRocketLaunch(fn: (r: { building: number; x: number; y: number; victory: boolean; launches: number }) => void): void Um foguete foi lançado.
events.onEnemyDefeated(fn: (e: EnemyDefeated) => void): void Um inimigo foi derrubado (type: o id dele no JSON; ai: o comportamento; data: o que este mod guardou nele com e.data). O mesmo que enemies.onDefeated.

world

O mundo: tempo, chão, construções, itens no chão, mensagem a todos.

Membro O que faz
world.readonly tick: number Tick atual do mundo (30 por segundo).
world.readonly seed: number Semente do mundo.
world.readonly name: string Nome do mundo.
world.readonly timeOfDay: number Hora do dia de 0 a 1 (0 = meia-noite, 0.5 = meio-dia).
world.readonly day: number Número do dia.
world.message(text: string): void Mensagem para todos no chat.
world.tile(x: number, y: number): Tile O que há num tile: terreno, jazida, vegetação, construção.
world.buildingAt(x: number, y: number): BuildingInfo \| null A construção que ocupa o tile.
world.findBuildings(opts?: { type?: string; x?: number; y?: number; radius?: number }): BuildingInfo[] Construções numa área (até 500; radius em tiles, padrão 32).
world.dropItems(x: number, y: number, item: string, count?: number): number Larga itens num monte no chão; devolve quantos couberam.
world.build(type: string, x: number, y: number, rotation?: number): Building \| null Constrói sem jogador e sem gastar item (rotation 0–3). null se não cabe.
world.remove(id: number): boolean Tira uma construção do mundo (sem devolver nada).

players

Jogadores: lista, mensagens, teleporte, inventário.

Membro O que faz
players.list(): Player[] Todos os jogadores do mundo (online ou não).
players.get(id: number): Player \| null Um jogador pelo id.
players.message(id: number, text: string): void Mensagem só para um jogador.
players.teleport(id: number, x: number, y: number): boolean Leva o jogador até (x, y) se ali dá para ficar (não dentro de veículo).
players.give(id: number, item: string, count?: number): number Põe itens no inventário; devolve quantos couberam.
players.take(id: number, item: string, count?: number): number Tira itens do inventário; devolve quantos saíram.
players.count(id: number, item: string): number Quantos daquele item o jogador tem.
players.isAdmin(id: number): boolean Se o jogador é administrador do servidor.

storage

Dados do mod salvos com o mundo (qualquer valor que vire JSON; até 1 milhão de caracteres).

Membro O que faz
storage.get(key: string): any Lê um valor guardado (null se não há).
storage.set(key: string, value: any): void Guarda um valor (vai no save do mundo).
storage.delete(key: string): void Apaga um valor.
storage.keys(): string[] As chaves guardadas.

commands

Comandos no chat (/nome).

Membro O que faz
commands.register(name: string, fn: (player: Player, args: string[], text: string) => string \| void, opts?: { admin?: boolean; description?: string }): void Cria /name no chat. O que fn devolve vai só para quem digitou. admin: true = só administradores.

buildings

Construções: máquinas com script, clique, procurar, construir.

Membro O que faz
buildings.onTick(type: string, ticks: number, fn: (b: Building) => void): void Chama fn para cada construção do tipo (ex.: "meu_mod:prensa") a cada ticks ticks — é assim que se faz máquina nova.
buildings.onInteract(type: string, fn: (b: Building, player: Player) => void): void Um jogador clicou numa construção do tipo (precisa de "script": true no JSON).
buildings.get(id: number): Building \| null Uma construção pelo id.
buildings.at(x: number, y: number): Building \| null A construção que ocupa o tile.
buildings.find(opts?: { type?: string; x?: number; y?: number; radius?: number }): Building[] Como world.findBuildings, já como objetos.
buildings.build(type: string, x: number, y: number, rotation?: number): Building \| null Como world.build.

O objeto de uma construção (b)

O objeto de uma construção (o b de buildings.onTick e afins).

Membro O que faz
readonly id: number Número da construção.
readonly info: BuildingInfo & { enabled: boolean; power: number; recipe: string \| null; inventory: Stack[]; slots: MachineSlots; fluids: FluidBox[] } \| null Tudo de uma vez (null se ela não existe mais).
readonly type: string Tipo (id da construção no JSON).
readonly x: number Canto de origem (tile).
readonly y: number Canto de origem (tile).
readonly exists: boolean Se ainda está no mundo.
readonly working: boolean Se está trabalhando agora.
readonly power: number Quanto da energia pedida chegou (0 a 1).
enabled: boolean false desliga a máquina (qualquer uma): não trabalha nem pede energia. Vai no save.
wantsPower: boolean Máquina de mod com "power" no JSON: true enquanto quer energia (veja quanto chegou em power).
readonly inventory: Stack[] Itens do baú (container).
readonly slots: MachineSlots Máquina: entrada, combustível, saída e subproduto.
readonly fluids: FluidBox[] Tanques de líquido.
count(item: string): number Quantos daquele item ela tem (baú e espaços da máquina).
insert(item: string, count?: number): number Põe itens como um braço poria; devolve quantos entraram.
extract(item?: string, count?: number): number Tira itens (somem); sem item, qualquer um. Devolve quantos saíram.
addFluid(fluid: string, amount: number): number Põe líquido nos tanques; devolve quanto entrou.
takeFluid(fluid: string, amount: number): number Tira líquido; devolve quanto saiu.
neighbors(): { side: "east" \| "south" \| "west" \| "north"; building: Building }[] Construções encostadas, com o lado.
readonly data: { get(key: string): any; set(key: string, value: any): void; delete(key: string): void } Dados deste mod nesta construção, salvos com o mundo (somem quando ela sai).
remove(): boolean Tira do mundo (sem devolver nada).
animate(name: string \| null, opts?: { loop?: boolean; speed?: number }): void Toca uma animação do .bbmodel (qualquer uma). null volta à do estado (animations no JSON).
pose(bone: string, pose: { rotation?: [number, number, number]; position?: [number, number, number]; spin?: [number, number, number] } \| null): void Pose de um osso, somada à animação: rotation (graus), position, spin (graus por segundo, girando sempre). null tira.

enemies

Inimigos e MEKs: criar, procurar, um código por tipo a cada tick. O comportamento de cada um é um dos 7 do jogo (ai no JSON); o script pode assumir o controle com ordens.

Membro O que faz
enemies.types(): EnemyType[] Todos os inimigos que existem (do jogo e dos mods), com os números do JSON.
enemies.spawn(type: string, x: number, y: number): Enemy \| null Cria um inimigo no ponto (a casa dele fica ali). null no mundo Pacífico, em chão onde não se anda e para o MEK de segurança (que precisa de um Posto). Até 50 por tick.
enemies.get(id: number): Enemy \| null Um inimigo vivo pelo id.
enemies.list(opts?: { type?: string; x?: number; y?: number; radius?: number }): Enemy[] Os vivos (até 500); com radius, só os perto de x, y, do mais perto ao mais longe.
enemies.near(x: number, y: number, radius?: number, type?: string): Enemy[] Os vivos até radius tiles (padrão 16) do ponto, do mais perto ao mais longe.
enemies.onTick(type: string, ticks: number, fn: (e: Enemy) => void): void Chama fn para cada inimigo vivo do tipo (ex.: "meu_mod:sucateiro") a cada ticks ticks.
enemies.onDefeated(fn: (e: EnemyDefeated) => void): void Um inimigo foi derrubado, com os dados que este mod guardou nele (e.data). Como events.onEnemyDefeated.

O objeto de um inimigo (e)

O objeto de um inimigo (o e de enemies.onTick e afins). Posição em tiles, com fração (10.5 = meio do tile 10).

Membro O que faz
readonly id: number Número do inimigo.
readonly info: EnemyInfo \| null Tudo de uma vez (null se ele caiu ou sumiu).
readonly type: string Id do inimigo no JSON.
readonly ai: string O comportamento: sentinel, warden, mek, rogue_mek, scavenger, dismantler ou watcher.
readonly x: number Posição (tiles, com fração).
readonly y: number Posição (tiles, com fração).
readonly exists: boolean Se ainda está vivo no mundo.
health: number Vida. Mudar cura ou fere (até maxHealth); 0 derruba, como um golpe (solta a sucata).
readonly maxHealth: number Vida cheia (do JSON).
readonly friendly: boolean true para o MEK de segurança do jogador.
readonly state: string guarding (parado), chasing (andando/lutando), returning, patrol ou dying.
readonly controlled: boolean true enquanto segue ordens do script (o comportamento do jogo fica parado). Não vai no save: ao abrir o mundo ele volta ao normal até o script mandar de novo.
moveTo(x: number, y: number): void Ordem: andar até o ponto (contorna água e construções) e parar lá.
attackPlayer(player: Player \| number): boolean Ordem: ir atrás do jogador e bater. Quando ele cai, fica parado esperando ordem.
attackBuilding(b: Building \| BuildingInfo \| number): boolean Ordem: ir até a construção e bater até derrubar.
attackEnemy(e: Enemy \| number): boolean Ordem: lutar com outro inimigo ou MEK.
stop(): void Ordem: ficar parado onde está (também assume o controle).
release(): void Devolve ao comportamento do jogo (ele volta para casa ou segue o que fazia).
damage(amount: number, by?: Player \| number): void Fere. Se cair, a sucata vai para by (ou para quem estiver perto).
remove(): boolean Some do mundo sem soltar nada e sem o evento de derrubado.
readonly data: { get(key: string): any; set(key: string, value: any): void; delete(key: string): void } Dados deste mod neste inimigo, salvos com o mundo. Quando ele cai, vêm no evento onDefeated (data) e depois somem.

ui

Telas: janelas com as peças do jogo, avisos e texto no HUD.

Membro O que faz
ui.show(player: Player \| number, form: Form, onEvent?: (e: { button: string; fields: Record<string, string>; closed: boolean; player: Player }) => void): void Abre (ou atualiza, com o mesmo id) uma janela para o jogador. Clique, Enter num campo e fechar chamam onEvent.
ui.close(player: Player \| number, id?: string): void Fecha a janela.
ui.toast(player: Player \| number, text: string, color?: string): void Aviso rápido embaixo da tela (color: accent, danger, energy ou #rrggbb).
ui.hud(player: Player \| number, id: string, text: string \| null): void Linha fixa no alto da tela (até 8); null tira.

research

Pesquisas.

Membro O que faz
research.list(): Tech[] Todas as pesquisas com o estado de cada uma.
research.readonly current: string \| null A pesquisa em andamento.
research.select(id: string \| null): boolean Escolhe a pesquisa do laboratório (null = nenhuma).
research.isDone(id: string): boolean Se a pesquisa está concluída.
research.level(id: string): number Nível de uma pesquisa infinita.
research.grant(id: string): boolean Conclui (e libera as receitas); infinita: +1 nível.
research.progress(units?: number): void Unidades de presente para a pesquisa atual.
research.bonus(effect: string): number Soma das infinitas com esse efeito (mining_speed, crafting_speed, research_speed ou um do mod).

contracts

Contratos dos Nós (um por região).

Membro O que faz
contracts.list(): ContractState[] O contrato ativo de cada região, com o ritmo e o tempo mantido.
contracts.finish(region: number): boolean O contrato ativo da região fecha no próximo tick, com as recompensas.

random

Sorteio com semente do mundo (igual em todo servidor que roda o mesmo mundo).

Membro O que faz
random.next(): number Número de 0 a 1 (igual a Math.random(), que também tem semente).
random.int(min: number, max: number): number Inteiro de min a max (inclusive).

console

Mensagens para o console (F8 no modo desenvolvedor, ou o console do servidor).

Membro O que faz
console.log(...values: any[]): void Mensagem.
console.info(...values: any[]): void Mensagem.
console.warn(...values: any[]): void Aviso (amarelo).
console.error(...values: any[]): void Erro (vermelho).

Funções soltas

Funções soltas.

Membro O que faz
after(ticks: number, fn: () => void): void Chama fn uma vez, daqui a ticks ticks.
