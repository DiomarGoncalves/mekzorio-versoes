Documentação para fazer mods

Mods do MEKZORIO têm dados (arquivos JSON), arte (modelos do Blockbench, ícones e sons) e, quando precisam de um comportamento novo, scripts em JavaScript que rodam trancados no servidor. Tudo aqui é gerado dos textos do próprio jogo (versão 0.2.2-alfa).

Como fazer um mod

Do zero: pastas, manifesto, itens, máquinas, receitas, arte, som, scripts, multijogador e mapas.

Campos do JSON

Cada lista e cada campo que um mod pode declarar, com o valor padrão e o limite.

API dos scripts

Cada função que o script do mod pode usar (gerada do próprio jogo).

Para baixar

Mod de exemplo com script (motor rotativo + caixa de engrenagem)

mekzorio.d.ts — autocompletar da API no VS Code

Ponha o mekzorio.d.ts na pasta scripts/ do seu mod: o VS Code passa a mostrar cada função e o que ela faz enquanto você escreve. O jogo também traz os exemplos na pasta mods; eles também estão na aba Mods.
