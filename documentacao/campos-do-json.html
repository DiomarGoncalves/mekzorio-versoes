Referência de mods do MEKZORIO

Manual completo de tudo o que um mod pode declarar (a API dos scripts está em API dos scripts). Para começar do zero, leia antes o Como fazer um mod (passo a passo, pastas, manifesto, multijogador). Esta página é a consulta: cada lista, cada campo, o valor padrão e o limite aceito.

Tudo aqui foi tirado do carregador do jogo (src/Automacao.Core/Content/ContentLoader.cs). Campo com nome errado vira erro (não passa despercebido), e cada erro diz o arquivo, o id e o motivo.

Convenções

Assunto Regra
Arquivos content/*.json no mod. Aceita comentários // e vírgula sobrando no fim. Os arquivos são lidos em ordem alfabética.
Ids Letras minúsculas, números e _. Sem prefixo, o id é do seu mod ("forno" vira meu_mod:forno). Para usar algo de outro mod, ponha o prefixo: "base:iron_plate".
Textos { "pt-BR": "Forno", "en": "Oven" }. Sem a língua do jogador, usa a outra que existir.
Cores "#rrggbb". É a cor usada enquanto não há ícone ou modelo.
Tempos Em segundos (o jogo roda a 30 passos por segundo).
Ordem Algo só pode ser usado depois de carregado: num mod anterior (dependência) ou mais acima no mesmo arquivo. Itens antes das construções e receitas que os usam.

Listas que um arquivo pode ter: items, terrain, resources, flora, buildings, recipes, research, contracts, worldgen e player (os dois últimos normalmente só o base usa).

Manifesto (manifest.json)

Campo O que faz
id Nome do mod (letras minúsculas, números e _); é o prefixo dos ids dele (meu_mod:forno).
name Nome que aparece na tela de Mods ({ "pt-BR": …, "en": … }).
version Versão do mod (1.0.0). Servidor e jogador precisam da mesma.
authors Lista de autores.
description Texto da tela de Mods.
gameVersion Versões do jogo em que funciona (">=0.2.0").
apiVersion Versão da API de mods (JSON e scripts) para a qual o mod foi feito: hoje 1 (o padrão, sem o campo). Se um dia a API mudar algo que os mods usam, ela sobe para 2 e o jogo continua rodando os mods 1 como antes; um mod de uma API mais nova que a do jogo é recusado com o aviso "atualize o jogo".
dependencies Outros mods que ele precisa, com a versão: { "base": ">=0.2.0" } (para o base, use >=). Carregam antes.
side "both" (padrão).

Itens (items)

{ "id": "tijolo_refratario", "name": { "pt-BR": "Tijolo refratário", "en": "Fire brick" },
  "stackSize": 100, "color": "#b0563c" }
Campo Padrão O que faz
stackSize 50 Quantos cabem num espaço (1 a 100000).
color — Obrigatório.
fuel 0 Segundos que o item mantém uma máquina queimando (0 a 3600). Carvão = 20. Item com fuel serve de combustível.
fluid false É um líquido (água, vapor, óleo). Líquido não vai para o inventário: anda em canos e tanques.
ammo 0 É munição: % do dano da arma ou torreta (100 = normal, 170 = perfurante).
module — Módulo de máquina: { "speed": 25, "energy": 0 } = % a mais de velocidade e de gasto de energia (negativo economiza).
jetpack false Equipado nas costas, J liga o voo. Use junto com "equip": { "slot": "back" }.
equip — Equipamento: slot (back, body, hand ou weapon); miningSpeed (ferramenta na mão: coleta N vezes mais rápido); armor (no corpo: % a mais de vida); weapon (range tiles, damage, cooldown s).
vehicle — Veículo (ver abaixo).
floor — Item de chão: o id do terreno que ele põe (o jogador calça arrastando; recolher devolve o item).

Veículos (vehicle dentro do item)

"vehicle": { "type": "cargo", "slots": 32, "fuelSlots": 0, "maxSpeed": 8, "capacity": 0 }
type O que é Campos que importam
locomotive puxa o trem, queima combustível fuelSlots (1 a 10), maxSpeed (tiles/s)
cargo vagão de carga slots (até 200)
fluid vagão de líquido capacity (até 100000)
car carro livre (sem trilho) slots (porta-malas), fuelSlots, maxSpeed
helicopter, airplane voam por cima de tudo slots, fuelSlots, maxSpeed (até 60)

Locomotivas e vagões são postos em cima do trilho; o carro e os aéreos, no chão.

Construções (buildings)

{
  "id": "forno_tijolo", "item": "forno_tijolo", "color": "#a4513a", "size": [ 2, 2 ],
  "crafter": { "category": "smelting", "fuel": true, "speed": 2 },
  "ports": [ { "x": 0, "y": 0, "side": "west", "type": "input" }, { "x": 1, "y": 0, "side": "east", "type": "output" } ]
}

Campos de toda construção

Campo O que faz
item O item que a coloca (precisa existir; cada item coloca uma construção só).
size [largura, altura] em tiles, de 1 a 8.
ports Portas de item: x, y (tile dentro da construção, na orientação original: a frente é o leste), side (east, south, west, north) e type (input ou output). Esteiras e braços entram e saem por elas; no jogo aparecem como setas ciano (entra) e amarelas (sai).
power { "use": 90 } (kW, 1 a 100000): a máquina usa eletricidade. Para máquinas (miner, crafter, lab, inserter, droneHub, pump, lamp…), não para esteira, baú, gerador, poste ou divisor; com "fuel": false. Liga sozinha, por cabo, ao poste mais perto no alcance dele.
fluidBoxes Tanques de líquido: lista de { "type": "input" ou "output", "capacity": 100, "filter": "base:water" }. filter (opcional) prende o tanque a um líquido.
fluidPorts Onde o cano liga: { "x", "y", "side", "box" } (box = índice em fluidBoxes). No jogo aparecem como uma gota com o nome do líquido.
wall Muro: aguenta mais golpes.
script true: máquina de mod controlada por script (buildings.onTick, buildings.onInteract); o clique avisa o servidor. Com script, um container pode ter power.
ownWindow Com script: o clique abre só a janela do script (ui.show), não a janela padrão da máquina.
animations Animações do .bbmodel por estado: { "working": "work", "idle": "parado", "noPower": "sem_energia" } (trabalhando — padrão work —, parada, sem energia). O script também toca qualquer uma (b.animate).

Comportamento (exatamente um por construção)

Bloco Para quê Campos (padrão)
belt esteira speed (1.875 itens/s por fileira), texture, rail (texturas)
splitter divisor 1×2 buffer (2, de 1 a 16), speed (1.875)
tunnel esteira subterrânea ou aérea range (5, de 2 a 16), speed (1.875), aerial (false)
inserter braço (1×1) time (0.8 s por viagem), reach (1 a 3 tiles), dropReach (onde solta, 1 a 3; padrão = reach), stack (1 a 12 itens do mesmo tipo por viagem)
miner mineradora time (2 s por minério), fuel (true), trees (alcance para cortar árvores; 0 = mineradora comum)
crafter fornalha, montadora, planta ver abaixo
container baú slots (16), logistics (none, provider = drones pegam daqui, requester = drones trazem o pedido)
generator gerador output (kW), source (fuel, solar, wind, steam), fuelRate (1), steamPerSecond (vapor; precisa do tanque de entrada 0)
battery banco de baterias capacity (kJ), rate (kW)
pole poste reach (7 tiles de fio), cable (alcance do cabo até as máquinas; padrão = reach), top (altura do fio)
lab laboratório slots (4, de 1 a 16), speed (1; 2 = o dobro, de 0.1 a 20)
droneHub central de drones range (25), slots (16), speed (6), cargo (5)
pipe cano ou tanque capacity (100), underground (0 = cano comum; N = passa por baixo até N tiles)
offshorePump bomba d'água rate (100 por segundo), fluid (o líquido que tira); precisa de um tanque de saída
wagonPump bomba de vagão rate (50)
pump bomba de cano rate (200 por segundo); precisa de 2 fluidBoxes (entrada 0, saída 1) e de power
rail, trainStop, railSignal trilho, estação, sinal {} (sem campos)
turret torreta range (10), damage (10), cooldown (0.5 s); gasta itens com ammo
security posto de MEKs meks (3), scrap (10 por MEK), time (30 s), radius (14)
reactor reator ver abaixo
lamp luminária true (sem campos); precisa de power: pede energia só à noite e acende sozinha (cubos glow* do modelo brilham e o jogo põe uma luz quente)
prospector sonda de prospecção { "radius": 24, "seconds": 120, "finds": 3, "patch": 3, "amount": [4000, 8000], "resources": [ids] }; precisa de power: a cada seconds com energia revela um veio patch×patch de um dos resources (todos com "prospected": true) num lugar livre a até radius tiles, com amount por tile, e marca no mapa; para depois de finds veios
silo silo de foguete ver abaixo (junto com crafter de receita fixa)
node Nó de Reativação slots (8) — o mundo cria os Nós; um mod normalmente não precisa
pile, wreck, ruin monte de itens, destroços, ruína true + container — saque que some quando esvazia (o jogo cria)

crafter

"crafter": { "categories": [ "assembling", "hand" ], "fuel": false, "selectRecipe": true, "speed": 1, "maxIngredients": 4 }
Campo Padrão O que faz
category / categories — Que tipos de receita faz.
fuel true Queima combustível (fornalha de pedra). Elétrica: false + power.
selectRecipe false true = o jogador escolhe a receita (montadora). false = escolhe pelo que entra (fornalha).
speed 1 2 = o dobro (de 0.1 a 20).
maxIngredients — Nível da montadora: quantos ingredientes diferentes a receita pode ter (1 a 6).
recipe — Máquina de uma receita só (caldeira, refinaria, silo).

Para receitas com líquido, declare fluidBoxes (entradas e saídas) e fluidPorts. O n-ésimo tanque de entrada recebe o n-ésimo líquido de entrada da receita; o mesmo vale na saída.

reactor

"reactor": { "fuel": "uranium_fuel_cell", "spent": "spent_fuel_cell", "cellSeconds": 200, "steamPerSecond": 180, "maxHeat": 1000, "explodeRadius": 6 },
"fluidBoxes": [ { "type": "input", "capacity": 600, "filter": "water" }, { "type": "output", "capacity": 600 } ]

Precisa de 2 tanques: água na entrada 0, vapor na saída 1. Vapor sem saída abaixa as barras; sem água ele esquenta, avisa aos 50% e explode no máximo (explodeRadius tiles).

silo

"crafter": { "categories": [ "rocket_building" ], "recipe": "rocket_segment", "fuel": false },
"silo": { "segments": 100, "pieces": [ "a", "b" ], "payload": "orbital_satellite", "reward": { "orbital_pack": 500 },
          "countdownSeconds": 10, "ascentSeconds": 12 }

Monta segments (1 a 10000) com a receita do crafter. O primeiro lançamento leva as pieces (a vitória); os seguintes levam o payload e trazem a reward.

Receitas (recipes)

{ "id": "forno_tijolo", "category": "hand", "group": "production", "time": 1.5,
  "inputs": { "base:stone_brick": 10 }, "outputs": { "forno_tijolo": 1 } }
Campo Padrão O que faz
category — Onde é feita (ver tabela). Categoria nova só funciona se alguma construção a fizer.
group automático Aba da Fabricação: logistics, production, energy, intermediates, science, combat. Sem ele: construções vão para production, o resto para intermediates.
time 1 Segundos (na velocidade 1).
inputs, outputs — Item → quantidade. Pode ter líquidos (não em hand nem smelting). Um segundo item de saída vira subproduto.

Categorias do jogo base: hand (na mão e na montadora), smelting (fornalhas; 1 ingrediente), assembling (montadora), vehicles (montadora: veículos), chemistry (planta química), refining (refinaria), boiling (caldeira), centrifuging (centrífuga), rocket_building (silo).

Pesquisas (research)

{ "id": "forno_tijolo", "name": { "pt-BR": "Fornalha de tijolos" }, "description": { "pt-BR": "…" },
  "cost": { "base:automation_pack": 1 }, "units": 15, "time": 10,
  "prerequisites": [ "base:automation" ], "unlocks": [ "forno_tijolo" ] }
Campo Padrão O que faz
cost — Pacotes gastos por unidade.
units 10 Quantas unidades. 0 = já vem pesquisada (organiza a árvore).
time 5 Segundos por unidade.
prerequisites — Pesquisas antes desta.
unlocks — Receitas liberadas; começam bloqueadas até a pesquisa terminar.
deliver — Pesquisa de entrega (era 0): itens que o jogador entrega na tela (sem laboratório).
nodeOnly false Só um contrato da Rede libera (rewardResearch); o laboratório não pesquisa.
repeat — Pesquisa infinita: { "effect": "mining_speed" / "crafting_speed" / "research_speed", "perLevel": 10 } (% por nível). Cada nível custa units × (nível + 1). Outro nome em effect (letras minúsculas, números e _) é efeito do mod: o jogo só soma perLevel × nível e o script aplica (research.bonus("nome")).

Contratos (contracts)

{ "id": "tijolos", "region": 1, "stage": 1, "name": { "pt-BR": "…" }, "item": "base:stone_brick",
  "perMinute": 20, "seconds": 120, "rewards": { "base:iron_plate": 50 }, "rewardResearch": [ "forno_tijolo" ] }
Campo Padrão O que faz
region 0 0 = Nó do início; 1, 2… = Nós regionais. Cada região tem a sua fila.
stage 1 1 religar, 2 estabilizar, 3 ampliar.
item, perMinute, seconds — Pede produção contínua: perMinute do item, mantida por seconds.
rewards — Itens que vão para o depósito do Nó.
rewardResearch — Pesquisas concedidas (incluindo as nodeOnly).

O carregador recusa uma pesquisa nodeOnly que nenhum contrato libera.

Recursos (resources) e terrenos (terrain)

"terrain": [ { "id": "areia_vermelha", "name": { "pt-BR": "Areia vermelha" }, "color": "#b0603a", "walkable": true } ],
"resources": [ { "id": "estanho", "item": "estanho_minerio", "color": "#c8c8b4", "terrain": [ "base:rocky" ],
  "generation": { "scale": 40, "coverage": 0.02, "minAmount": 100, "maxAmount": 800, "starting": false, "region": 0 },
  "miningFluid": { "base:sulfuric_acid": 10 } } ]
Campo Padrão O que faz
terrain — Em que terrenos a jazida aparece.
generation.scale 40 Tamanho das manchas (4 a 1024).
generation.coverage 0.02 Fração do mapa coberta (até 0.5).
minAmount, maxAmount 100, 800 Minério por tile.
starting false Garante uma jazida perto do início.
region 0 0 = mapa todo; N = só em volta do Nó da região N (não pode ser starting).
miningFluid — Líquido gasto por minério (uma mineradora com tanque de entrada é necessária).
prospected false true = não nasce no mapa (o generation é ignorado): só uma construção prospector revela.

Terreno com "walkable": false vira água ou obstáculo. "walkSpeed" (100) é a % da velocidade de andar em cima dele (de 25 a 300; o caminho de pedra usa 130).

Plantas (flora)

{ "id": "pinheiro", "kind": "tree", "item": "base:wood", "amount": 4, "density": { "base:forest": 0.3 },
  "sapling": "muda_pinheiro", "grows": "pinheiro", "growSeconds": 300 }

kind: tree (corta e dá amount de item) ou decor (só enfeite). density = chance por bioma. sapling, grows e growSeconds deixam replantar. sway (0 a 0.5, padrão 0.08 na árvore e 0.05 no enfeite) = quanto o topo balança com vento forte, em tiles; 0 deixa parado (pedras, cacto). O tronco da árvore fica firme.

kind também pode ser wreck (destroço, resto da Rede antiga): desmonta-se segurando o clique como uma árvore e dá amount de item, não deixa construir em cima, mas o cortador de árvores não mexe nele. remnant põe o destroço nos sítios de restos da geração (belt, rail, pole, machine ou car; com mais de um no mesmo papel, o jogo sorteia), e align (true) vira o desenho para o vizinho igual (esteira e trilho em linha). Sem remnant, ele só nasce pela density, como qualquer planta.

{ "id": "trator_velho", "kind": "wreck", "item": "base:mechanical_scrap", "amount": 8, "remnant": "car" }

Inimigos e MEKs (enemies)

{ "id": "sentinela_blindada", "name": { "pt-BR": "Sentinela blindada" }, "ai": "sentinel",
  "health": 900, "damage": 9, "hitTime": 2, "speed": 10, "sight": 10, "leash": 28, "scrap": 4, "weight": 1,
  "model": "sentinela_blindada", "animations": { "walk": "andar", "idle": "respirar" } }
Campo Padrão O que faz
ai — Comportamento: sentinel, warden (Guardião do Nó), mek (MEK do jogador), rogue_mek, scavenger, dismantler, watcher (voa).
health 120 Vida (1 a 1000000).
damage 4 Dano por golpe (0 = não bate).
hitTime 1 Segundos entre golpes.
speed 17 Velocidade (sentinela 17, Guardião 12, coletor 22).
sight 10 Até quantos tiles enxerga.
leash 28 Até quantos tiles se afasta de casa perseguindo.
scrap 2 Sucata mecânica que deixa ao cair.
weight 1 Com mais de um inimigo do mesmo ai, a torre sorteia por esse peso (0 = nunca sozinho: só quando um script cria, com enemies.spawn).
model o id O .bbmodel ("base:warden" usa um do jogo).
animations — walk (andando) e idle (parado); sem elas, toca a work.

Jogador (player) e mundo (worldgen)

"player": { "startingItems": { "base:burner_miner": 1 } } dá itens no começo da Carreira.

worldgen é do base; um mod só mexe se quiser um mundo diferente (o último mod que define vale):

Campo Padrão O que faz
elevationScale 96 Tamanho (tiles) das ondas de relevo que escolhem as faixas.
bands — Faixas de terreno por altura: [{ "terrain": "base:water", "coverage": 0.12 }, …] (de baixo para cima; coverage = fração do mapa).
startingArea — Área do começo: radius (48: terra firme e plana em volta do início), patchRadius (6: raio das jazidas iniciais), minDistance/maxDistance (12 / 36: a que distância do início elas ficam).
biomeScale 600 Tamanho (tiles) das regiões de bioma.
remnants — Sítios de restos da Rede antiga (mundos novos): cell (56: o mapa é dividido em células desse tamanho, 32 a 512), chance (0.3: de cada célula ter um sítio) e minDistance (70: nunca mais perto do início). As peças são as plantas de kind wreck com remnant. Sem o campo, nenhum resto.
abandonedLines — Linhas de produção abandonadas (mundos novos; decisão 216): cell (192, múltiplo de 32: tamanho das células), chance (0.5: de a célula ter uma linha), minDistance (110: nunca mais perto do início) e layouts: as plantas, cada uma com id, weight (1: chance relativa), ores (minérios sorteados para nascer embaixo das mineradoras) e pieces: building (a construção), at ([x, y] relativo à planta) e facing (east, south, west ou north; east se faltar). As peças nascem paradas e enferrujadas; com o Nó da região religado, o MEK zelador restaura cada uma que o jogador pagar (metade da receita da máquina). Sem o campo, nenhuma linha.
biomes — Lista de biomas: id, name, color, temperature e moisture ([mín, máx], 0 a 100), terrains (que terrenos aparecem) e resources (multiplicador das jazidas: { "base:iron_ore": 1.5 }).

Teto da demo (demo)

Um objeto só (o último mod que definir vence), usado apenas em mundos com a regra Demo (pacote demo do jogo): "demo": { "research": [ ids ], "contracts": [ ids ] }. Pesquisa fora de research aparece com "Disponível na versão completa" e não pode ser escolhida (as de nascença sempre valem; uma ganha de presente por contrato também); o contrato fora de contracts para a fila do Nó dele. Ids que não existem dão erro ao carregar. O jogo base define o seu em mods/base/content/demo.json.

Arte, som e idiomas

Por convenção de pastas, sem declarar nada:

Arquivo no mod Usado como
textures/items/<id>.png ícone do item, 16×16 pixel art (aparece em 32 px, nítido)
textures/resources/<id>.png, textures/terrain/<id>.png jazida e chão
models/<id da construção>.bbmodel modelo 3D (Blockbench): 16 unidades = 1 tile, frente em +X
sounds/<id da construção>_loop.wav som da máquina trabalhando (WAV mono 16 bits, em laço)
sounds/<nome>_1.wav, _2.wav… variações de um efeito; um mod pode trocar um som do base com o mesmo nome
icon.png (ao lado do manifesto) ícone do mod na lista, 32×32

Peças do modelo: nome com chimney/stack/exhaust solta fumaça; começando com glow brilha; com accent pega a cor do jogador. A animação work toca enquanto a máquina trabalha. Sem arte, o jogo usa color e um modelo simples.

Exemplos que vêm com o jogo

Mod Mostra
mods/fornalha_tijolos item, construção com portas, receita, pesquisa (o mais simples)
mods/exemplo_destilaria líquidos: tanques de entrada e saída, portas de cano, receita com líquido, categoria nova
mods/mecanica_exemplo script: motor rotativo a carvão + caixa de engrenagem que prensa engrenagens; máquina nova (script: true), dados por máquina, vizinhos, peças do modelo girando (pose com spin), janela própria com botões e barra (ui.show, onInteract); modelos gerados por arte/mecanica_exemplo_modelos.py
mods/base tudo o que o jogo tem (é carregado pelo mesmo sistema)

Os exemplos são carregados por testes automáticos: se uma mudança do jogo quebrar um deles, os testes avisam.
